## What Is NetCrunch

NetCrunch is a network picture for a lab, a school building, or a small office you look after. NetCrunch network map is the picture. NetCrunch snmp poll fills it with live marks from devices that trust this management station. You are watching your own network, the one whose passwords and addresses you already hold as an administrator.

NetCrunch node status is what you glance at in the morning. NetCrunch alert rule is what speaks up if a node drops while you are in class or in another room. NetCrunch dependency view stops you from treating five quiet PCs as five separate mysteries when they all hang off one switch. For a modest site, that combination is more useful than a wall of unrelated charts.

The daily loop stays short. Open NetCrunch network map, read NetCrunch node status, and trust NetCrunch snmp poll for the numbers behind a mark. If something looks wrong, use NetCrunch dependency view before you walk to the wiring closet. NetCrunch alert rule should already have told you the same story if you stepped away.
